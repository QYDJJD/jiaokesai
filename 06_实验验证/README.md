# 实验验证

本模块检验情景库、模型和协同策略在指定条件下是否有效，并明确其适用范围。当前已有[描述性阶段验收与后续验证方案](描述性情景库验收与后续验证方案-v1.md)，区分文稿技术检查、业务执行审查和未来独立验证。新增[分级方法假设验证](分级方法验证/验证说明.md)：10张假设卡、120组配置、14类性质检查。只支持简化原型的条件性检验；实际阈值和独立验证未完成。

## 拟研究内容

对照方案、实验情景、参数设置、数据划分、重复与复现条件、效果指标、敏感性分析和极端情景检查。每项实验应说明它验证哪个研究问题。

比较峰值滞留、受影响群体清空时间、资源投入等指标时，统一人群、时间起点、安全条件和资源约束。使用独立事件检验；没有独立样本时如实报告验证范围。

## 输入与输出

输入包括[情景库](../03_情景库/README.md)、[数据与案例](../02_数据与案例/README.md)、[建模](../04_建模/README.md)和[协同调度](../05_协同调度/README.md)。输出为实验配置、结果数据、比较图表、结论和局限，并反馈需要修订的情景或模型，供[成果输出](../07_成果输出/README.md)引用。
