# 优化模型验证

本目录只记录OPT-MILP-01的新模型验证，不沿用旧分级原型的通过次数。

- [平台14项检查](test_platform.py)、[结果](平台检查结果.json)和[浏览器流程验收](平台流程验收.json)：检查中文输入接口、手工安排、异步进程及导出复用，不合并为模型实证样本。使用方法见[交互平台](../../04_建模/交互验证平台/README.md)。
- [13项自动检查](test_model.py)及[测试结果](测试结果.json)：小例穷举、无预算、缺参、人数口径、准备、零需求、相同历史、车辆占用、未来服务、站立和密度、下游关闭、共享容量及初始候客。
- [全量优化实验](优化实验结果.json)：12组条件实验，6组有经独立核对的可行排班，6组在当前候选集合内不可行。主方案、名义方案、全座较高预算、放宽站立及最小费用5组达到所设差距；较高预算等待优化1组达到时限，保留可行解及0.188%左右的首阶段差距。
- [存档复查程序](verify_saved.py)及[核对记录](存档结果核对.json)：校验代码及输入哈希，重放21条可行优化过程和8条基准过程，共29条，核对人数、等待、车辆、舒适、截止及因果约束。

小例12名旅客、两班6座公交，经穷举得到最小累计等待240人分钟，优化器与其一致。主实验采用6000人的研究群体和四个可能进入过程，均为合成参数，不是实际需求测量。另保留当前队列执行器及两个未参与优化的压力过程，展示已列集合之外的适用边界。

时间模型为段初批量进入、段末服务完成；一分钟独立核对仍采用这一事件约定，不提供连续真实客流的精度证明。求解界限、目标版本与结果性质详见[模型说明](../../04_建模/接续运输优化原型/README.md)及[结果报告](../../07_成果输出/接续运输优化原型与虹桥事件背景实验-2026-10-19.md)。
