# 分级方法假设验证说明

日期：2026年10月10日。用途：检验[分级候选原型](../../03_情景库/原定分级方法可行性论证-v2.md)在简化假设下的方向、边界和可复现性。**所有输入均为合成假设，不是虹桥实际数据。**

## 一 复现方式

Python 3标准库，无第三方依赖。进入本目录运行：

```powershell
python verify_grading.py
```

脚本会覆盖本目录内两份生成结果：[验证结果](验证结果.json)和[120组参数配置](参数网格结果.json)。配置是5个Q×4个D×3个P1×2个供给系数，非历史事件。完整输入见[脚本](verify_grading.py)，数值容差1e-8。

## 二 假设与计算

K=1000人、H=1小时、B0=0；V0有效服务500人/小时；V1增援500、V2再增援1000，增援时滞各1小时，默认P1=1小时。方向完全兼容，资源无重复、共享瓶颈或服务截止；人流连续可分，有队列时按上限服务，无退出或安置。输入均匀；不确定性对照另允许80%在前四分之一输入期、20%在其余时间到达。

在所有输入与生效变化时点精确积分，常率段内队列线性增长或降至0，不存储闲置能力；因此峰值可在变化点查得。群体完成条件为最后输入后队列清空。零供给有需求时完成时间为null。通过条件为峰值不大于K且完成不晚于D+H；F3仅表示预设V0-V2均未通过。

## 五 不能由此推断什么

本次14类检查支持原型的实现一致性和条件性性质，不构成实际等级准确率、阈值标定、策略最优性或独立样本验证。K/H、参考包、实际方向、离散班次、共享瓶颈、信息质量、旅客行为及安全条件均需进一步确认。假设网格有限，解析性质也只在本文前提下适用。
