# 描述性情景库验收与后续验证方案 v1

日期：2026年10月10日。当前开展的是文稿、来源与口径检查；没有运行数值实验。描述性阶段验收和未来模型验证分别记录。

## 一 本阶段交付检查

| 检查项 | 当前材料及结论 | 结论范围 |
|---|---|---|
| 来源与身份 | [台账](../02_数据与案例/案例与来源台账-T-C4初稿.md)与[五张卡](../03_情景库/描述性情景卡集-v1.md)对应；实际事件、常态、准备及计划分别标识 | 可追溯到报道，不等于原始日志核验 |
| 主对象与版本 | 用户确认夜间晚点继续疏运范围；团队和导师待确认 | 当前写作范围，非正式预案范围 |
| 字段及未知 | 五主轴与补充约束均有定义，缺失未填0或正常 | 字段定义成立，实际取值仍不足 |
| 生成与选择 | A6流程、规则、保留理由及[覆盖矩阵](../03_情景库/情景覆盖矩阵-v1.md)齐备 | 描述性归纳可交付，不证明完备性或真实概率 |
| 动作与权限 | [动作接口](../05_协同调度/情景到协同动作接口-v1.md)区分历史、计划、建议和待核权限 | 可用于讨论，未经授权不能作执行指令 |
| 判据方向 | 原Λ的解析反例已给；B_max、T_clear使用条件已限定 | 逻辑审查，不是模型复现或经验验证 |
| 综述与差异 | 代表综述、A3方法对照及新增论文核查有来源和证据等级 | 不能作系统综述、全领域空白或创新成立证明 |
| 正式复核 | 保留现有成员记录，本次仅助手技术整理 | 三人评审、万岩松本人接口复核及导师确认仍待实际填写 |

本阶段具备描述性材料包的内容交付条件；正式作品提交验收仍取决于团队/导师意见与要求的文件格式。数值分级、调度效果及独立泛化不在当前通过范围。

## 二 下一阶段可验证的问题

| 问题 | 验证设计 | 通过前需要的证据 |
|---|---|---|
| 字段是否遗漏影响动作的条件 | 对新的未参与设计事件提取同一字典；检查需要动作但无字段表达的情况 | 原始/完整记录、危害与权限，新增字段理由 |
| 情景能否解释动作差异 | 对同类事件固定人群、窗口和资源条件，比较实际准备及服务差异 | 完整信息与动作链；不能仅凭报道篇幅不同认定差异 |
| 拟议动作能否执行 | 请具备相应职责者核资源、授权、安全和冲突；记录拒绝或修改理由 | 适用预案版本、资源承诺、生效和现场条件 |
| 模型能否核算需求积压 | 首先检查人数平衡和口径，再比较预测序列与实际序列 | B0、分时进入/转出、方向、服务；说明残差和截尾 |
| 策略是否改善疏运 | 在同输入、同预算、同安全与权限约束下比较现状基线和候选策略 | 实际基线、可复现参数及必要的行为依据；报告代价和未完成需求 |

## 三 数据分组与评价边界

E01、E02已用于字段与生成流程设计，不能再作为该方法的独立外部留出检验。新增事件若用于修订规则，身份转为设计数据；若用于校准参数，不再用于宣称同参数的独立检验。同一事件不同报道、时段和方式记录同组管理。事件数量少时，只报告案例内一致性与适用边界。

未来评价可分别报告固定群体的B_max、T_clear、累计等待、方向未服务需求、资源投入和对常态服务的影响；每项先给定义、单位与可观测条件。安置人数单列，未完成需求和观察窗截尾单列，不因队列转移而宣称疏运成功。没有真实事件总体或概率样本，不报告发生概率或统计覆盖率。

## 四 升级门槛与停止条件

资料只有汇总报道时，维持描述性路线。若仅部分字段补齐，先完成口径核算和区间讨论，不自动进入优化或绝对分级。完整输入与验证分组形成后，由团队重新确定模型、对照和算法；无需为配合已选算法而补造数据。

本阶段停止继续扩充的条件：每张卡有来源和角色、每个讨论问题有依据或缺口、每个候选动作有执行前提、每项结果声称符合实际证据强度。这一条件用于阶段收尾，不声称整个课题已经完成。
