# 情景库

10月11日修订5入口：[现行分方向与共享规则](分方向与共享约束判级规则-v2.md)、[初始库v2](初始情景库-v2.md)、[新增验证](../06_实验验证/分级方法验证/分方向验证说明.md)。当前32张合成检查卡＋4张真实材料卡；下列v1文件保留为单池前版和背景。

本模块回答课题研究哪些运营冲击，以及如何将它们组织为可比较、可用于调度研究的情景。

总体研究包括白天、夜间与跨日过程。当前例证包括铁路晚点、航空转场和台风方式限制，后续按人群、服务、空间与动作缺口补充；时段通过实际服务条件进入情景。

## 当前材料

- [分级规则与判级依据](分级规则与判级依据-v1.md)：用户已选择“需要哪档运力保障”；给定目标和供给曲线下取最低通过层，明确实际校准及策略优化限制。
- [初始情景库](初始情景库-v1.md)及[结构化JSON](初始情景库-v1.json)：18张合成卡与4张真实材料卡，逐层输入、结果、失败原因及目标变化。
- [本版验证与适用性审查](../06_实验验证/分级方法验证/初始库验证与适用性审查.md)：32项检查、786次比较与117组目标变化；不等同于真实准确率。
- [原定分级方法可行性论证](原定分级方法可行性论证-v2.md)：复原五维＋Λ，指出结构问题，提出参考资源包目标满足原型，并明确已证与未证范围。
- [前版假设验证](../06_实验验证/分级方法验证/验证说明.md)：10卡、120组配置及可复现代码；保留历史，不和新库重复计数。

- [描述性情景卡集](描述性情景卡集-v1.md)：4张事件卡、1张常态对照、2张计划和1张演练参考卡；逐卡列事实、主轴缺失与讨论问题。
- [情景覆盖矩阵](情景覆盖矩阵-v1.md)：时段、人群、影响、动作与结果等12项条件及缺口与保留理由；不是总体覆盖率或完备性证明。
- [情景生成方法方案（T-A6）](情景生成方法方案-T-A6.md)：案例归纳与抽样/聚类比较、筛查流程、八张不同用途的材料卡，待万岩松审核接口。
- [枢纽情景库构建方案](枢纽情景库构建方案v1-文献论证稿-优化版.md)：研究边界、三项衔接问题、五个候选主轴、补充约束、候选判据与校准方案。
- [突发事件定义与研究边界](突发事件定义与研究边界.md)：将事件类型识别、运行状态指标和协同调度边界分开，明确情景库以运营状态而非灾害名称作为主要输入。
- [超大型综合交通枢纽判定与适用边界](超大型综合交通枢纽判定与适用边界.md)：用规模底线、方式耦合、网络门户和应急协同复杂性判断哪些枢纽适合接入本课题评价体系。
- [多方式划分与纳入规则](多方式划分与纳入规则.md)：按应急调度属性划分冲击源方式、运营组织型方式、协调型资源、企业调度/市场动员型方式和约束型设施/通道。
- [协同联动定义与方法](协同联动定义与方法.md)：定义协同联动的信息共享、触发条件、响应时序、权限接口和能力约束，明确其与多方式划分的区别。

## 后续研究内容

情景要素字典、事件与危害标签、方式和空间可用性、情景分类或分级规则、生成与筛选方法、代表情景集以及来源记录。情景数量、阈值和生成算法在证据与数据满足条件后确定。
