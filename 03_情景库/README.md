# 情景库

本模块回答课题研究哪些运营冲击，以及如何将它们组织为可比较、可用于调度研究的情景。

## 当前材料

- [枢纽情景库构建方案](枢纽情景库构建方案v1-文献论证稿-优化版.md)：研究边界、三项衔接问题、五个候选主轴、补充约束、候选判据与校准方案。
- [突发事件定义与研究边界](突发事件定义与研究边界.md)：将事件类型识别、运行状态指标和协同调度边界分开，明确情景库以运营状态而非灾害名称作为主要输入。
- [超大型综合交通枢纽判定与适用边界](超大型综合交通枢纽判定与适用边界.md)：用规模底线、方式耦合、网络门户和应急协同复杂性判断哪些枢纽适合接入本课题评价体系。

## 后续研究内容

情景要素字典、事件与危害标签、方式和空间可用性、情景分类或分级规则、生成与筛选方法、代表情景集以及来源记录。情景数量、阈值和生成算法在证据与数据满足条件后确定。

## 与其他模块衔接

输入来自[文献资料](../01_文献资料/README.md)和[数据与案例](../02_数据与案例/README.md)。向[建模](../04_建模/README.md)提供需求、可用性、信息条件和约束组合，向[实验验证](../06_实验验证/README.md)提供测试情景及覆盖要求。
