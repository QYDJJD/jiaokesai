# 事件画像与案例检索原型

[模块A接口与数据字典 v0.2](模块A接口与数据字典-v0.2.md)列出事件、来源、候选、去重、人工确认及MILP接口。`research_workflow.py`提供模拟文档适配器与证据候选生成，不执行网络搜索；可运行`python 03_情景库/事件画像与检索/test_research_workflow.py`检查。

运行`python -X utf8 03_情景库/事件画像与检索/run_research_demo.py`生成[模拟证据候选](demo-模拟证据候选.json)；其中example.org为模拟来源，片段只是演示文本，不能引用为真实材料。

本目录是模块一的结构化输入首版：手工录入事件字段，验证来源、时间和数据状态；对四条突发事件与一条常态对照资料做可解释匹配；输出模型字段对照及缺口。合成研究参数包可通过桥接程序生成网络卡并调用既有求解与独立核算。本机10月27日演示页提供对照检索入口，尚未接入真实调度。

在仓库根目录运行：

```powershell
python 03_情景库/事件画像与检索/engine.py 03_情景库/事件画像与检索/demo-事件画像.json --output 03_情景库/事件画像与检索/demo-检索结果.json
python 03_情景库/事件画像与检索/test_engine.py
python 03_情景库/事件画像与检索/test_bridge_http.py
python 03_情景库/事件画像与检索/verify_retrieval.py
python 03_情景库/事件画像与检索/run_bridge_demo.py
```

修改示例JSON可模拟其他事件；已知字段必须写来源及带时区的时间，未知为null。分类值先经过engine.py中列出的有限同义词映射再精确匹配；其他词保持原值，不进行自然语言抽取或语义检索。输出可比字段覆盖率、匹配字段、差异及缺失；覆盖率低于0.5时提示复核，0.5是演示阈值，不代表经校准的可靠度。已列输入有值也仅表示需要进一步检查，不代表可以直接进入模型。

2026年11月19日更新：排序先区分覆盖率是否达到演示阈值0.5，再在组内按匹配比例和覆盖率排序；无可比字段排在末尾。低覆盖结果仍保留供核查，0.5不是统计置信度，也不保证排序准确。候选抽取在已有概括字段时仍显示具体候选并提示核查细节；只有明确列入`fixed_indicators`的同一指标ID才被排除。该规则只使用模拟材料，结果仍须人工复核。

示例与HQ-E01属于同一历史事件，已通过event_family_id排除自身；同事件的其他报道也必须使用同一event_family_id。未提供该字段时退回event_id，系统无法自动识别不同ID是否同一事件，需人工核对。新事件须记录独立来源。真实调度须补齐逐方向逐时段需求、网络、服务能力、资源和安全授权。假设参数应单独标注，禁止将案例受影响人数转为当前待接续人数。

[检索测试样例](检索测试样例.json)包含10条人工构造查询，用于检查排序、差异、缺失、低覆盖与同事件排除；[结果](检索功能检查结果.json)不等同独立真实样本评测。扩充真实事件后应由不参与规则调整的人员先标注相关性与安全差异，再按事件留出测试。

[真实事件人工标注与检验方案](真实事件人工标注与检验方案.md)提供标签、工作表及内部/外部验证边界；当前没有代填人工标签。启动本地研究平台后，从研究工作台侧栏的“情景检索—决策演示（本机）”进入，在第二步使用“运行结构化对照检索”。该对照使用本目录案例库及规则，原演示下方的历史算法和后续候选措施保持独立。

真实事件检验材料：[20组标注工作表](真实事件人工标注工作表.md)、[空白标签模板](真实事件标签-待填写.json)、[评估程序](真实事件评估.py)。未完成标签冻结时不能运行正式评估；现有案例留一结果只能作为内部回顾性探索。

[20组助手初判](真实事件案例标注-助手初判.md)与[对应数据](真实事件标签-助手初判.json)可用于团队复核；该初判由参与规则开发的助手提出，不能充当独立人工金标准。若需独立标签，标注人先不看初判及排序，独立记录后再对照讨论。未代填人类签名，未冻结或计算真实检索准确率。

桥接示例的画像保留10008名历史受影响旅客，并另外显式假设12名待接续旅客；完整网络参数取自现有tiny手算示例，全部为研究假设。程序核事件ID、需求总数、初始人数、参数包各部分假设来源和NETWORK-CARD-02格式；输出网络卡、来源指纹与求解复算摘要。其他画像字段尚未自动映射，来源粒度为参数分组而非逐字段，不支持真实资源授权或历史回放。参数包是人工完整输入，而非由检索自动推断。

BRIDGE-02增加单过程逐群体逐时段到达数组的一致性检查；必须明示“假设可继续运输”和“仅允许合成研究计算”，未知或不满足则停止生成。安全和研究计算条件均是合成假设，不代表现实安全核查或调度授权。来源记录逐叶字段给出JSON路径与值，继承参数组的假设来源，并非逐字段原始证据。

启动[本地平台](../../04_建模/交互验证平台/README.md)后，在`/research`侧栏进入“事件画像桥接（合成研究）”，选择`demo-合成画像.json`和`demo-合成参数包.json`，核对并下载网络卡及来源记录；导入现有工作台后仍需用户主动检查和运行。字段变化后须重新核对，桥接页不会自动调度或启动求解。
