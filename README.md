# 虹桥枢纽应急协同调度研究

课题：突发事件下超大规模交通枢纽多方式协同联动策略。

当前核心成果为**五维情景组织结构与目标约束下的保障层次分级方法**。已完成关键词定义、研究边界、五维选择及口径论证、32张合成检查卡和4张真实材料卡。新增五组受控例证及72组组合的252对比较，支持P1、U、D、Q、R在当前研究任务中各有区分作用；同五维异初始积压反例明确必须保留附属细节。现版汇报以五维可行性和建库方法为主体，理论、独立核算、边界与目标敏感性为计算支撑。研究覆盖白天、夜间与跨日，等级表达“需要哪档运力保障”，候客上限与完成时限为主条件，个人等待为补充。结论不包括五维独立充分、唯一最优或虹桥真实阈值已校准。

先读[文件一：关键词与边界](07_成果输出/导师汇报一-关键词解释与研究边界-2026-10-12.md)和[文件二：五维依据与可行性](07_成果输出/导师汇报二-情景库五维划分依据与可行性-2026-10-12.md)，核心依据见[五维划分可行性论证](03_情景库/五维划分可行性论证-v1.md)及[五维验证结果](06_实验验证/分级方法验证/五维划分验证结果.json)，计算支撑见[成立条件与证明](03_情景库/分级方法成立条件与理论验证-v1.md)及[完整验证说明](06_实验验证/分级方法验证/方法完整验证说明.md)。真实材料用于核对象、约束与边界；运营后台接入、实际标准核定及现场试用属于成果应用条件，不作为本阶段研究未完成项。公开来源台账保留；已被替代的报告可从Git历史追溯。

本仓库按课题的研究模块组织：文献和案例提供依据，情景库定义研究场景，建模表达供需与约束，协同调度形成策略，实验验证比较效果，成果输出汇总最终作品。任务安排和过程记录集中放在项目管理中。
