# 虹桥枢纽应急协同调度研究

课题：突发事件下超大规模交通枢纽多方式协同联动策略。

**给老师展示：**打开[情景库思路演示](07_成果输出/情景库思路演示.html)，载入“预测开始窗口5—30分钟”，点击“计算当前事件评定”。准备需20分钟时，主提示按最早5分钟给二级，同时保留二、三级范围；人数与候客压力另列。再改一个参数、重新计算，或展示六组成对检查。可保存新版本、复制、比较和导入导出；真实报道原型的未知参数保留为空。单文件可离线打开，本机平台首页同样提供，完整工作台位于 `/research`。

**当前重点（2026年10月25日）：先描绘和评定事件，再研究交通处理。** [事件评定原型02](03_情景库/事件描绘与紧迫程度评估原型.md)已实现底板/时段引用、逐项证据、开始时间区间、缺参时保留已知危险或超限、修改后隐藏旧结果，以及本地版本库。四档是研究提示，未映射官方预警或响应。首次信息提前量与当前剩余时间分开，进入节奏与预测不确定性分开。下列材料按各自阶段保留。

**当前研究定位（2026年10月21日）：情景库建模与事件评估为主要研究内容。** 枢纽相对稳定条件、常态时段规律和事件扰动分层组织，形成可复用的参数情景及评估输入。既有预案、论文指标与调度方法提供处置参照；前期自拟“现有／加强／联合”档位属于历史方法试验，不作为当前的正式事件等级或主要创新点。

平台第一步已调整为事件条件评估，报告候客峰值、占所设上限的比例、完成时间和截止剩余，并可引用已有预案或论文方法。[研究方案](04_建模/情景库驱动的接续运输优化模型研究方案-v1.md)说明研究贡献与应用验证的关系；[使用说明](04_建模/交互验证平台/README.md)说明当前功能。展示页已采用有限底板/时段注册表及版本化情景；完整网络工作台仍保存自身完整输入，尚未迁移，也未自动接收新评定卡。

**2026年10月20日平台实现记录：**双击[启动研究平台](启动研究平台.cmd)，在本机浏览器先通过主要参数预判保障档位，再配置任意方式、节点、线路、资源池、旅客去向和服务日历，优化或核对手工安排。[平台使用说明](04_建模/交互验证平台/README.md)与[通用网络模型](04_建模/多方式网络优化/README.md)说明完整流程。快速预判完成12项专门检查及36组独立累计核对，网络模型完成24项通用性与约束检查，并用四种不同结构的卡调用同一求解器；虹桥作为一张真实背景例证。数据和运行记录保存在本机，不自动同步到GitHub。

**2026年10月19日研究推进：**已从情景库扩展出[可运行的接续运输优化模型](04_建模/接续运输优化原型/README.md)，接通情景卡、资源安排、具体排班与独立复算。已完成12组条件实验及13项自动检查。虹桥降雪事件背景实验在声明参数下，用6辆备用车安排19班、预约1600个出租服务名额，费用23980元，四种进入过程均满足候客上限与05:30完成要求。[8页结果报告](07_成果输出/接续运输优化原型与虹桥事件背景实验-2026-10-19.pdf)汇总比较、验证及边界；[研究方案](04_建模/情景库驱动的接续运输优化模型研究方案-v1.md)保留文献依据与扩展路线。数值为合成参数实验，不表示历史处置改善率。

前期情景库方法探索形成**五维情景组织结构与目标约束下的保障层次分级方法**。已完成关键词定义、研究边界、五维选择及口径论证、32张合成检查卡和4张真实材料卡。新增五组受控例证及72组组合的252对比较，支持信息提前量、到达不确定性、旅客进入持续时间、新增待接续人数、方式与空间服务状态各有区分作用；同五维异初始积压反例明确必须保留附属细节。汇报正文采用中文字段，汇报二以十项研究比较、逐维定义、受控检验和建库方法论证五维可行性。真实事件模拟与处置对比见[独立案例报告](07_成果输出/真实事件模拟与对比-虹桥降雪晚点.pdf)，完成声明假设下的分级调度、逐维决策检查、同资源比较和201次过程核算。理论、独立核算、边界与目标敏感性为计算支撑。研究覆盖白天、夜间与跨日，等级表达“需要哪档运力保障”，候客上限与完成时限为主条件，个人等待为补充。结论不包括五维独立充分、唯一最优或虹桥真实阈值已校准。

先读[文件一：关键词与边界](07_成果输出/导师汇报一-关键词解释与研究边界-2026-10-12.md)和[文件二：五维依据与可行性](07_成果输出/导师汇报二-情景库五维划分依据与可行性-2026-10-12.md)，核心依据见[五维划分可行性论证](03_情景库/五维划分可行性论证-v1.md)及[五维验证结果](06_实验验证/分级方法验证/五维划分验证结果.json)，计算支撑见[成立条件与证明](03_情景库/分级方法成立条件与理论验证-v1.md)及[完整验证说明](06_实验验证/分级方法验证/方法完整验证说明.md)。真实材料用于核对象、约束与边界；运营后台接入、实际标准核定及现场试用属于成果应用条件，不作为本阶段研究未完成项。公开来源台账保留；已被替代的报告可从Git历史追溯。

本仓库按课题的研究模块组织：文献和案例提供依据，情景库定义研究场景，建模表达供需与约束，协同调度形成策略，实验验证比较效果，成果输出汇总最终作品。任务安排和过程记录集中放在项目管理中。
