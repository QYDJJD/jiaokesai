# 虹桥实际应用待调研参数清单 v0.1

日期：2026年10月28日。用途：事件画像、接续运输网络模型和候选措施的输入核查；来源为拟联系对象和项目已有资料，未联系任何单位。统一按事件、人群、方向、时间窗和空间边界记录；未取得值保留未知。

| 数据项 | 单位及时间/空间口径 | 可能的持有方或资料 | 调研方式与使用边界 |
|---|---|---|---|
| 受影响人数 | 人；事件和列车或航班窗口 | 铁路、机场、运营统计 | 请求字段定义及去重方法；不直接当待接续人数 |
| 新增待接续人数及方向 | 人；时间步×起点×目的地方向 | 铁路/枢纽客流统计、调查 | 核继续出行与自组织离开；明确多种方式是否可替代 |
| 初始候客 | 人；事件窗口起点和各候客区域 | 枢纽运营及客流监测 | 核原有积压、统计时刻与事件人群，避免重复计入到达 |
| 预计/实际到达过程 | 人/时间步；预计版本、更新时间和方向 | 铁路列车时刻、客流系统 | 请求预测与实际分开及各版本时间戳；不以事后值替代当时预测 |
| 候车安全容量 | 人或人/平方米；区域和启用时间 | 场站管理及安全方案 | 核面积、密度依据、共享通道和人群适用条件；不凭模型确定现实阈值 |
| 轨交既定和可增开服务 | 班、座位或有效人/班；方向、时段、站点 | 轨交运营方及适用预案 | 核末班、沿途停靠、换乘、余量和正式批准；名义容量不等于有效余量 |
| 公交可用资源及司机 | 车、人、座位/车；车辆基地、准备时间、方向 | 公交企业、调度机构 | 请求上岗时间、装载、首末班、行程/返程/周转；区分车辆与班次 |
| 出租服务 | 车/时间步、人/车；上客点、可服务方向 | 出租企业、枢纽调度 | 核实际到达率、载客、蓄车与进出站周转；等待时间不当调度延迟 |
| 网约车或其他名额 | 人/时间步、服务窗口、费用 | 平台与协调单位 | 区分已确认服务包与预测；核失约和授权 |
| 道路及共享设施 | 可用/受限/未知、有效容量/时间步 | 交警、交通委、场站管理 | 请求位置、管制时间、公交/出租共享节点；道路限行与行程时间分开 |
| 下游接收及换乘 | 人/时间步、开闭时刻、目的方向 | 地铁及接驳节点运营方 | 核车站/线路容量及实际接续条件，区分离开起点与到达目的节点 |
| 重点帮助人群 | 人；需求类型及可接受方式 | 车站服务台及脱敏现场统计 | 核无障碍、行动、陪护及分配条件；数量不足以推定服务能力 |
| 信息与调度时点 | 带时区时间：获知、下令、接令、确认、生效、终止 | 指令单及运营日志 | 同一动作跨机构对时；预测提前量与方式调度滞后分开 |
| 权限与资源承诺 | 允许/待确认/不可用；主体、依据和有效期限 | 适用预案、主管部门、运营单位 | 核正式指令与协调请求；未获批不当作已兑现资源 |
| 费用及服务目标 | 元/资源单位；分钟、人分钟、期限等 | 预算规则、合同、管理目标 | 区分预约成本、票价与社会成本；目标与假设在实验前确定 |
| 事后结果与独立事件 | 分时进入离开、方式使用、实际完成和未完成 | 运营日志、站区记录 | 单独保留未用于规则或参数拟合的事件；数据可得不等于自动可验证因果效果 |

已有公开案例与来源见[案例台账](案例与来源台账-T-C4初稿.md)；现有公开数据大多缺少上述分时及权限字段。建议先询问可否提供脱敏、聚合的数据和口径说明，再确定样本范围与使用权限。
