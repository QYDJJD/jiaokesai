# 虹桥夜间疏散案例口径核查

本页为万岩松审核T-A5数据接口的示例，不替代张子凡主责的完整案例参数表。

## 2023年12月14日保障记录

来源：上海市交通委员会《市交通委指挥中心全力做好虹桥火车站夜间大客流疏散交通保障工作》，页面标注2023-12-19；事件发生于12月14日至15日。[官方记录](https://jtw.sh.gov.cn/xydt/20231226/6f4ed792491949fb871c7237e4d636ff.html)

| 字段 | 原文记录 | 可用解释 |
|---|---|---|
| 工作指令 | 12月14日21:28下发 | 组织动作时间；不是每种方式接令或到位时间 |
| 晚点影响 | 23:00至次日5:00涉及28班、10008人 | 受影响旅客口径；不是同时滞留峰值或超常态积压 |
| 地铁 | 加开3班运送273人次，2号线延至0:30 | 实际报道运量；不是地铁最大可用能力 |
| 夜宵公交 | 316、320路共20班，运送32人次 | 报道覆盖的公交实际运量；不能推得全部公交能力 |
| 出租车 | 平均等候5—15分钟 | 乘客等待指标；不是车辆调度响应滞后 |
| 疏散结束 | 次日5:10 | 官方记录的完成时点；不能直接计算每位旅客等待时间 |

以上为单一事件的一组字段，不是多个独立样本。官方记录未给出租车总运量、滞留人数曲线、全部去向、常态有效能力或各方式到位时间。不能将10008减去地铁及公交运量后的余数全部归给出租车，也不能反推出某种方式成为主要疏散方式的原因。

## 用于校准之前需补充

按统一边界记录初始滞留、分时进入与离开、受影响群体、方向需求、常态剩余能力、新增能力、道路与场站限制以及各方式接令/生效时间。公交载客人数少可能由需求、线路、时点或服务范围影响，目前无法识别具体原因。

原稿1万及3.6—4.3万人次的报道数量只能作为场景规模线索，未取得专项预案全文前不称固定阈值。多篇报道指向同一次事件时合并为一个事件ID；另选未参与设阈值的事件进行检验。当前尚未具备绝对等级校准或独立验证条件。
