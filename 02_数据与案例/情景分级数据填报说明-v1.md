# 情景分级最小数据填报说明

2026年10月11日。配套[空白JSON模板](情景分级数据模板-v1.json)。用于核对一件完整事件，未知填null或“未知”，不是0。模板不直接进入计算；补齐并完成口径核对后，才转为RULE-02输入。

## 一 先确认“在算哪批人”

写清事件、地点、输入入口、起止和共同人群。“虹桥当天所有到达旅客”“一班晚点列车旅客”“已经候车准备去某方向的人”是不同群体，不能直接混算。先确定决策时点：此刻知道什么、已来了多少人、预计还会来多少人。事后实际值另列，不能改写当时预测。

再写清完成点：是上车离开候客区，还是抵达接收站点？合成工具计算前者，不能据此声称整段行程结束。各方向人群须互不重复；多目的地可接受者需先规定分配。

## 二 必要字段及含义

| 填报项 | 直白含义 | 要解决的判级问题 |
|---|---|---|
| 方向/目的地 | 这批人要去哪里，哪些接续点可接受 | 哪些车或线路真正能服务他们 |
| B0 | 计算开始时已经在等的人 | 起点已有积压是否超目标 |
| 分时进入人数 | 每个同长度时段新加入这批候客的人数 | 人是慢慢来，还是集中来 |
| 预测快照及联合轨迹 | 决策时认为各方向可能怎样同时/先后到达 | 方案是否覆盖允许的不同情况 |
| K及其来源 | 指定候客区允许的研究人数上限 | 哪种峰值算超标；与现场安全核定分列 |
| D及H | 输入持续多久；最后一批到达后容许再用多久完成 | 何时必须完成；不要填乘客等待时间 |
| 资源身份与方向 | 同一批车、线路或服务池的唯一编号、可去方向 | 防重复算和错方向 |
| 有效率与起止 | 同口径可实际留给研究群体的人/小时，何时能开始、何时结束 | 不能拿最大理论率延续至整夜 |
| 既有占用与增援生效 | 原有业务已用了多少；请求、承诺、到位、开始服务的时刻 | 剩余常态能力和新增能力分开 |
| 共享服务/候客设施 | 哪些服务共用上客点，哪些人共用候客区及限额 | 既不能重复加能力，也不能漏共同积压 |
| 候选方案 | 每层把哪些资源、在什么时段分给哪个方向 | 规则实际检查的保障安排是什么 |
| 路径/安全/权限/网络版本 | 该服务在当时是否能走、能用、能承诺 | 不适用条件不能靠人数等级覆盖 |
| 同群体完成与离开 | 每方向实际完成时刻、分时离开人数 | 用实绩核对计算而非报道结束时刻 |

个人最长等待继续作补充，不设无依据的正式上限。不能由“全体完成及时”推所有人等得短；可以先核对排队样本或进入—离开配对，缺失仍留空。

## 三 公共资料可以先填哪些格

[2024年官方保障计划](https://jtw.sh.gov.cn/xwfb2/20240930/7769eb329bfe431fb7db305392dbc778.html)列有方向性接驳安排，可以帮助资源方向和服务类型字段，但不能证明执行率、有效能力或最低等级。计划参考不要填进另一个事件的实际资源包。

[2025出租设施答复](https://jtw.sh.gov.cn/jyjabljg/20251211/f948d3c9c58f4fc6a0c59f58ad707a91.html)提供车辆发车极限线索；转为有效人/小时，还缺实际载客、车辆、占用、方向和场站条件。原资料单位及年份保存，转换值另附依据；若只有辆/小时，不能直接放入人/小时字段。

目前公开材料能填事件角色、部分动作、方向/时间和设施线索，仍缺完整同口径数值。不以模板“每格都填满”为完成标准，也不据空格认定原机制无效。

## 四 建议的核对顺序

先拿一件小范围完整事件：确认群体与时点→分方向需求→真实V0/V1/V2及共享设施→K/H来源→核资源方案→回放。一件完整开发事件可检口径和过程，不能替代未参与开发的独立验证。

K/H是需带来源的服务目标；V0/V1/V2是需带承诺条件的资源层。用户已确认等级用途及两个主条件，具体业务值仍由适用研究或运营依据确定。导师讨论可先审方法、字段和数据可得性，不必现在任意选一个虹桥“标准值”。
