## 后续研究内容

事件台账、分时到达与离开、初始滞留、旅客去向、常态剩余能力、应急新增能力、各方式接令与生效时间、道路和场站状态。取得原始数据后按原始数据、整理数据和参数字典归类，保留来源及转换方法。

统一事件ID、时间窗、空间边界、人群和单位；分别标记观测、推算、假设和缺失。校准样本与独立检验样本按事件区分，同一事件的多篇报道只计一次。
