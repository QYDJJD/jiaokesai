# 数据与案例

本模块整理虹桥真实事件和可用于情景、建模与验证的数据。

## 当前材料

- [虹桥案例口径核查](虹桥案例口径核查.md)：核对2023年12月14日官方保障记录，说明可用字段与缺失信息。

## 后续研究内容

事件台账、分时到达与离开、初始滞留、旅客去向、常态剩余能力、应急新增能力、各方式接令与生效时间、道路和场站状态。取得原始数据后按原始数据、整理数据和参数字典归类，保留来源及转换方法。

统一事件ID、时间窗、空间边界、人群和单位；分别标记观测、推算、假设和缺失。校准样本与独立检验样本按事件区分，同一事件的多篇报道只计一次。

## 与其他模块衔接

向[情景库](../03_情景库/README.md)提供取值依据，向[建模](../04_建模/README.md)提供参数和输入，向[实验验证](../06_实验验证/README.md)提供独立检验事件。当前案例核查是一个示例，完整案例参数表由张子凡按分工继续整理。
