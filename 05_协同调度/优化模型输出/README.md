# 优化模型策略输出

输入为[虹桥降雪背景合成卡](../../03_情景库/模型输入卡-虹桥降雪背景.json)，程序见[优化原型](../../04_建模/接续运输优化原型/README.md)，全量结果与状态见[实验记录](../../06_实验验证/优化模型验证/优化实验结果.json)。

| 文件 | 用途 |
|---|---|
| [公交排班](公交排班.csv) | 6辆合成备用车、19班任务的登乘、离站、接续节点到达和再次可用时刻 |
| [出租预约](出租预约.csv) | 分方向、分时段的1600个预约服务名额；不是1600辆出租车 |
| [策略对照](策略对照.csv) | 基础服务、平均预留与共同优化在四种进入过程下的条件结果 |
| [预算与舒适取舍](预算舒适取舍.csv) | 12组实验的状态、费用、候客、等待、站立及求解差距 |
| [候客过程图](候客过程对照.svg) | 统一边界下的研究候客曲线，可用于演示 |

所有费用和资源数值都是声明假设。最主要的共同方案使用23980元增量预算，候客峰值970人、最坏平均等待约15.97分钟、公交站立负担不超过3000人分钟，四种过程最晚05:30完成。共同方案的资源预约固定；优化器给出遵守相同观测历史限制的分配，采用只看当前候客的FIFO执行器复算也通过四种过程。

平均方案与优化方案使用相同24000元预算上限，但班次和预约组成不同：前者20班公交、1470个出租服务名额，费用23940元；后者19班、1600名额，费用23980元。不能称为完全相同资源或相同费用对照，更不能称为当年的实际方案对照。

方向甲的19班是本例人数、较短运行时间、较低费用和周转等条件下的计算结果；方向乙、丙主要由基础与出租服务保障。不能脱离这些参数推广为“公交永远优先某方向”。完整条件、求解状态、适用范围和后续工作见[结果报告](../../07_成果输出/接续运输优化原型与虹桥事件背景实验-2026-10-19.md)。
