# 协同调度

本模块研究给定情景与模型条件下，地铁、公交、出租车及网约车等方式如何准备、配置和衔接服务。当前已形成[情景到协同动作接口](情景到协同动作接口-v1.md)，明确候选动作、资源承诺、权限、安全和时间链。尚无调度求解或执行授权。

## 拟研究内容

方式可用性与可控性、协调请求与正式指令的权限、储备与预备动作、资源配置、服务方向、下令与生效时点、信息更新及备选策略。求解或策略生成方法应与模型和数据条件匹配。

## 输入与输出

输入为[建模](../04_建模/README.md)定义的供需关系与约束，以及[情景库](../03_情景库/README.md)给定的运行状态。输出为有明确适用条件、责任主体、资源需求和时间安排的候选调度策略，交[实验验证](../06_实验验证/README.md)比较。

实际组织响应和动员权限按适用预案核实。尚未取得授权依据的动作标为研究建议，不能写成正式操作指令。当前没有已求解的策略或已证明的效果。
