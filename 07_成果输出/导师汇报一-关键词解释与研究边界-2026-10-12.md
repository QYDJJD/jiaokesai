# 虹桥枢纽研究：关键词解释与研究边界

导师汇报文件一｜2026年10月12日｜资料截至2026年10月11日

本文件汇总课题现阶段统一采用的工作定义、对象划分及统计边界。五维情景划分的选择依据与可行性论证另见文件二。

## 1 课题对象与关键词体系

### 课题研究什么

课题为“突发事件下超大规模交通枢纽多方式协同联动策略”。本阶段以虹桥枢纽为研究对象，核心任务是建立面向接续疏运的情景库，明确情景需要记录哪些条件，再分析需要哪档参考运力保障。

“接续疏运”指铁路或航空旅客到达枢纽后，利用地铁、公交等继续出行。关注的是这些旅客如何获得适配的后续运输服务。研究涵盖白天、夜间及跨日；时间段本身不决定情景是否纳入，需结合当时的服务条件判断。

### 四个核心关键词的关系

| 关键词 | 本课题需要回答的问题 | 已采用的研究口径 |
|---|---|---|
| 突发事件 | 什么运营扰动进入研究 | 根据旅客需求、服务能力、准备时间和协同需要是否变化判断；事件类型与危害标签继续保存 |
| 超大型综合交通枢纽 | 什么对象适合采用本研究框架 | 综合考虑规模基础、多方式接续、区域门户功能及多主体协同复杂性 |
| 多方式 | 哪些方式或资源参与，分别承担什么作用 | 区分旅客到达来源、接续供给、协调资源、企业与市场供给，以及设施约束 |
| 协同联动 | 不同主体怎样围绕同一疏运目标配合 | 记录信息共享、触发条件、响应时序、权限接口和共同能力限制 |

这四个关键词先明确事件、对象和参与者，再明确参与者之间如何配合。它们构成五维情景库的研究前提，不按关键词名称直接给事件定级。

### 定义的采用范围

本文件中的定义是课题现阶段用于分析和建库的工作口径。枢纽的正式规模等级、预案响应级别及现场权限须分别引用适用标准、预案和运营规定；工作定义不构成正式认证或执行授权。

**已完成的基础工作是：统一研究词义，确定事件和方式的纳入规则，划定研究群体与统计边界，区分运输、安置及安全处置，并统一人数、能力和时间的记录口径。**

## 2 突发事件与枢纽对象的纳入规则

### 突发事件：按运营后果确定研究对象

本课题所称突发事件，是指天气、设施故障、运输组织异常、公共安全或外部交通扰动等因素，使特定区域和时段内的旅客到达、服务能力、换乘条件或准备时间发生变化，形成需要额外研究的接续疏运条件。

纳入时检查四项：待接续人数或到达集中程度是否变化；可用服务是否减少或受限；准备时间是否不足；是否需要多个单位或方式共同处理。四项均无相关变化、且可由常态资源吸收的小幅波动不单列为核心情景。

| 材料或事件 | 采用方式 |
|---|---|
| 列车或航班晚点、设施中断、道路受限 | 记录其造成的到达、接续和供给变化，符合研究边界时纳入 |
| 春运、节假日或赛事散场预测 | 作为计划或可预见压力对照；客流较大本身不等于法定突发事件 |
| 台风、火情、警情等 | 保留危害与管制信息；安全允许继续运输时研究其接续后果 |
| 医疗救援、防恐、抢险及设施修复 | 不作为本阶段主评价任务；其决定的禁行、隔离和救援优先等作为约束 |

### 超大型综合交通枢纽：按任务适用性判断

本课题所称超大型综合交通枢纽，是具有较大客流规模基础，集成对外交通与城市接续方式，承担区域集散或门户功能，并在运营扰动下存在跨方式传导和多主体协同需求的综合交通枢纽。

判断研究对象是否适合，检查规模基础、方式接续、区域功能及协同复杂性四方面。铁路或航空晚点会改变地铁、公交等的接续需求，这就是跨方式传导；各方式和设施分属不同单位，需要共同安排，就是协同复杂性。

虹桥“3+4”综合指挥体系由闵行区政府、市交通委、市公安局与机场、铁路、申通、地产四方参与，支持其作为多主体协同研究对象。[市交通委答复](https://jtw.sh.gov.cn/jyjabljg/20251211/f948d3c9c58f4fc6a0c59f58ad707a91.html)

“超大型”在本课题中用于描述对象适用性。设计年度日均发送量、实际到达量、到发量和节假日峰值属于不同统计口径。公开高峰数据能够说明运行压力，不能替代设计资料认证正式规模等级。

## 3 多方式角色与协同联动

### 按研究作用划分参与对象

多方式划分同时记录交通工具、运营主体、权限和研究作用。同一种方式在不同情景中可能承担不同作用，具体以该情景的任务和已确认条件为准。

| 类别 | 典型对象 | 进入研究的方式 |
|---|---|---|
| 到达来源，即冲击源方式 | 铁路、航空 | 记录何时、多少旅客进入；本阶段不优化其运行图或航班计划 |
| 运营组织型方式 | 地铁、常规公交、夜宵线、接驳公交 | 记录经确认的接续供给，以及延时、加开、加密等候选动作 |
| 协调型资源 | 储备车辆、增援人员、跨场站资源 | 记录能否承诺、由谁确认、何时开始提供服务 |
| 企业调度与市场动员型方式 | 出租车、网约车 | 区分企业或平台可兑现的服务，与尚未确认的社会弹性供给 |
| 约束型设施和通道 | 道路、候客区、上客点、换乘通道 | 限制有效服务和旅客流动；不作为另一份运输能力重复相加 |

私家车和亲友接送在有证据时可作为自组织离场记录，未经确认不计可承诺运力。出租或网约车辆也只有适配相应方向、时段且数量可核对时，才计入参考保障。名义座位多，不自动意味着旅客可以及时登乘。

### 协同联动的工作定义

协同联动是不同方式及其管理主体围绕同一疏运目标，根据共同的需求和服务信息，衔接准备、审批、提供资源及开始服务的时间，并共同遵守道路、场地和安全限制的协调行动。

| 要素 | 需要记录的具体内容 |
|---|---|
| 信息共享 | 旅客到达预测、候客人数、服务状态与更新时点 |
| 触发条件 | 什么需求或能力变化需要增加保障 |
| 响应时序 | 何时下令、接令、确认、到位，以及旅客何时真正能够使用服务 |
| 权限接口 | 谁可批准、谁可承诺资源、谁负责执行 |
| 能力约束 | 方向能否服务，道路能否通行，上客区和候客区能否承受 |

例如增加接驳公交，需要同时核查运营方能否提供车辆、主管主体能否批准、服务方向是否适配、上客区是否可用，以及何时开始载客。课题记录条件与候选动作，具体执行依适用预案和权限办理。

## 4 人群、空间、时间及完成边界

### 一张情景卡必须先确定什么

| 边界 | 当前统一口径 |
|---|---|
| 任务 | 铁路或航空旅客到达后的接续疏运；覆盖白天、夜间和跨日 |
| 人群 | 明确哪批已进入研究区域、且需要所研究后续服务的旅客；不直接使用全部受影响人数 |
| 空间 | 写明计入入口、候客区域、服务出口及目的方向；在范围内换队不重复计人 |
| 时间 | 写明决策时点、起算时点和同一群体的输入起止；跨午夜使用连续时间轴 |
| 完成 | 同一群体获得适配服务并离开指定候客边界；不等于到达最终目的地 |
| 安全 | 明确不宜继续运输时不作正常运输判级；安全条件未知时保留资料不足状态 |

### 人数如何避免混用

列车或航班总人数不自动等于待接续人数；取消航班但尚未到场的旅客不计入现场队列；起算时已经候客的人记初始积压B0，新进入的人另计。不同方向分别记录，避免把只能服务A方向的运力用来消除B方向需求。

安置、取消出行、自组织离场和去向不明分别记录。进入安置场所不能直接计作接续运输完成，队列人数为0也不自动证明原研究群体全部完成运输。资料不能辨认去向时，保留未知。

### 时间如何避免混用

输入期是这批新增旅客从首批到最后一批进入系统的持续时间。恶劣天气持续、服务停用和报道覆盖时间另记，不能相互替代。23:00起算时，次日01:00为第2小时。

消息获知、下令、车辆到场与增援生效是不同时间点。增援生效指旅客真正可以使用这项服务；接令或到位不一定已经可以上客。预测信息保存当时版本，不在事后用实际结果覆盖。

### 研究完成与现场处置的区分

本阶段完成定义、边界、情景组织和方法检验。实际现场救援、设施修复及运营执行不属于当前方法研究验收任务；相应规定和运行条件仍是研究的适用前提。

## 5 共同术语、数据口径及已完成成果

### 后续论证使用的术语

| 术语 | 本课题含义 |
|---|---|
| 情景与情景库 | 情景是决策时点的一组具体运营条件；情景库统一保存条件、来源、限制、目标和结果 |
| 情景划分 | 按信息提前量P1、不确定性U、输入期D、待接续人数Q、方式与空间服务状态R定位和比较情景；详细依据见文件二 |
| 保障分级 | 给定目标、参考资源与允许到达过程，判断需要哪档参考保障；等级是结果，不是情景字段的加权总分 |
| 有效服务率 | 对应方向、时段、资源和限制下，实际可提供给研究群体的服务量，例如人/小时 |
| 候客上限K | 研究指定的等待人数控制目标；不自动等于场所核定安全容量 |
| 完成余量H | 最后一批进入后允许继续服务的时间；不等于每位旅客最长等待时间 |

人数、服务率和时间均注明单位、区域及适用时段。车辆额定座位、全日运量和全网能力不直接替代某时段的有效服务率。保留事实、预测、计划、演练、合成假设和未知的区别；未知值不能填0，未查到增援不等于确认没有增援。

### 三类等级分别记录

预案响应级别表示按制度启动哪级响应；枢纽规模等级表示设施规模分类；研究保障级别表示哪层参考资源能达到本课题目标。三者没有预设一一对应关系，不能由报道“一级响应”倒推出研究F级。

### 基础工作的成果与作用

现阶段已经明确四个核心关键词及其联系，制定事件和方式纳入规则，统一人群、时空与完成边界，区分名义和有效能力，以及事实、假设和未知。它们使后续情景之间能够按同一对象、口径和目标比较，减少人数重复、时间替代和运力重复相加的问题。
