## 先用两分钟展示事件评定

[情景库思路演示](情景库思路演示.html)现以“参数输入→事件评定”为主。比较200人只剩5分钟准备、1200人提前120分钟获知、已确认直接危险三个示例，观察紧迫等级与规模如何分开。可修改五维、事件性质及补充目标后重新计算，查看准备时间余量、候客峰值范围、过程检查、等级理由和提示。页面附规则及来源、简短讲解；单文件可离线打开。[方法说明](../03_情景库/事件描绘与紧迫程度评估原型.md)记录设计和验证。

当前等级是处置紧迫程度的研究提示，未映射官方预警、法定事件或响应等级，也不直接换算车辆。准备时间、有效能力和控制目标为可修改的演示假设；事件性质与能力未知不填0。原三方式运输动画折叠在下方，作为使用自身参数的独立后续示例，不参与上方分级计算。
