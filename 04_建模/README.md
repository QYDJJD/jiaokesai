# 建模

**当前模型与交互入口：**[通用多方式网络模型](多方式网络优化/README.md)按节点、线路、任意方式、资源池和不同旅客群体求解，显式检查运行与换乘；[研究平台](交互验证平台/README.md)支持可视输入、日历、手工安排、结果和导出。双击[启动研究平台](../启动研究平台.cmd)即可使用。

本模块将情景中的需求、服务能力和时间条件表达为可分析的数学关系。2026年10月19日已实现[接续运输优化原型](接续运输优化原型/README.md)，包含情景卡输入、公交与出租安排、候客和舒适约束、求解与独立复算。12组条件实验、13项自动检查及具体排班见[结果报告](../07_成果输出/接续运输优化原型与虹桥事件背景实验-2026-10-19.md)。

[研究方案](情景库驱动的接续运输优化模型研究方案-v1.md)保留十二篇论文核查、舒适测度比较与扩展路线；已实现范围、运行方法和数值结论以原型及结果记录为准。公开事实与合成参数分别列示，实际运营参数尚未校准。

已有[数据字典与方法框架](数据字典与方法框架-v1.md)涵盖边界、证据属性、缺失处理和人数守恒；[分级原型](../03_情景库/原定分级方法可行性论证-v2.md)及既有核算作为基础与对照，验证结论不自动延伸到新优化模型。实际参数尚未校准。

## 拟研究内容

| 内容 | 需要明确的问题 |
|---|---|
| 需求与积压 | 分时到达、初始滞留、离开及旅客去向如何核算 |
| 运力与服务 | 常态剩余能力、新增能力、路线适配和场站通行如何表达 |
| 响应与到位 | 各方式从下令至运力生效的滞后如何进入约束 |
| 变量与目标 | 哪些量是输入、状态或决策；峰值积压、清空时间等目标如何定义 |
| 模型边界 | 安全、资源、权限与数据缺口如何限制结论 |

到达不确定性和信息提前量单独记录；调度滞后保持参数定位。当前已实现有限允许过程下的共同资源计划与相同观测历史约束；更细时间步、执行中滚动调整和感知舒适函数属于后续扩展。

## 输入与输出

输入为[情景库](../03_情景库/README.md)和[数据与案例](../02_数据与案例/README.md)，方法依据来自[文献资料](../01_文献资料/README.md)。输出为模型说明、变量与参数字典、目标和约束，以及供[协同调度](../05_协同调度/README.md)调用的接口。已有明确标识的假设结果，尚无已校准模型或真实效果结果。
