# 通用多方式接续运输网络模型

模型版本：NETWORK-MILP-02。输入格式：NETWORK-CARD-02。

本模型面向枢纽受扰后的城市接续运输，统一读取节点、线路、运输方式、资源池、旅客群体和进入过程。事件名称只保留为背景；方式名称只用于标识。虹桥是其中一张输入卡，另有轨道换乘、水路接续与手算示例。

研究采用两层评估：先用五维相关参数、目标及基准有效服务[评估事件条件](../交互验证平台/README.md)，再用本网络细化。第一层采用聚合队列，第二层检查换乘、车辆及设施等瓶颈；两层输入与完成边界分别保留。本程序承担情景输入核验和既有方法应用示范，不将自拟保障档位或调度算法作为当前主要创新。既有预案与论文参照见[来源登记](../交互验证平台/reference_rules.json)，未将摘要、演练记录自动转换为正式响应阈值。

## 一 通用性具体体现在哪里

| 可更换内容 | 怎样进入同一模型 |
|---|---|
| 枢纽与城市网络 | 自定义候客起点、换乘站、接续目的节点，以及它们之间的有向线路 |
| 运输方式 | 地铁、公交、网约车、出租、客运、渡轮、步行或自定义名称；按服务与资源属性计算 |
| 既定时刻与可用能力 | 逐时间步容量日历；可以表示停运、减容、恢复和间歇发车 |
| 新增运力 | 周转单位池或分时服务名额池；不同线路可共用资源 |
| 旅客去向 | 多个起点与目的节点、不同可接受方式、各自初始候客和进入曲线 |
| 需求不确定性 | 多条允许过程，可有不同总人数和去向构成；共用新增资源计划 |
| 目标与约束 | 累计全程时间、累计等待或预约费用；同时满足候客、截止、预算和已测度舒适条件 |

通用性已通过可执行检查：全部方式编号和名称替换后目标及费用一致；增加第五种方式及线路后无须修改求解器；道路中断示例使用渡轮与码头换乘；不同总需求、多起点、多目的节点及群体可接受方式均有检查。依据见[测试程序](../../06_实验验证/多方式网络验证/test_network.py)和[结果](../../06_实验验证/多方式网络验证/通用性与约束检查.json)。

## 二 三种服务与资源表达

### 1. 既定服务

已给定的时刻、容量和窗口，由模型分配旅客使用。地铁剩余能力或已确定列车可这样录入；模型不会因方式叫“地铁”就自动新增列车。座位与有效站立面积分别填写；可用座位不超过该段可用服务能力，取消服务后可用座位为0。

### 2. 需要周转的同质单位

按资源池记录可用车、船或其他同质单位，选择哪条线路、何时开始登乘、投入几个单位。完整占用包括登乘、去程、返回基地和周转准备，去程与返回可不同。给出实际单位编号并独立检查冲突。同一池从同一基地出发；多个基地分别建池。

### 3. 已确认的分时服务名额

按每包可服务人数、每时段包数、全程总包数和单价预约。可用于已确认的网约车、出租或其他服务名额；它表达有效能力，不推造逐辆车位置和周转。

这三种表达依赖服务属性，方式名称可以更改。同一方式可有多条线路、多个资源池；同一池的资源由多条线路共同占用。是否可以协调新增服务由输入声明，具体权限需另外核实。

## 三 旅客怎样经过网络

旅客按群体在指定起点进入，沿允许方式的线路运行。每次线路开始登乘前，旅客必须已经到达该节点；登乘与运行结束后才进入下一节点，换乘需要经过相应线路和时间。

采用时间展开网络，将每个节点在不同时间的状态区分开。模型同时计算待登乘、正在登乘、运行中和已到目的节点的人数。正在登乘仍占用候客空间；车上运行不再计作候客。每个节点、每个群体和全网络均有独立人数复算。

**两个完成口径分别报告：**

- 离开起点完成：所有任务旅客已经完成首次从其起点登乘并离开。
- 目的节点完成：所有任务旅客已经到达其设置的接续目的节点。中途转入拥挤换乘点不算完成。

可以分别设置两个截止。目的节点不代表家门口；其后的城市出行不在当前输入网络之外推算。

## 四 主要数学关系与指标

每个群体、节点和时间边界满足：

**本次开始登乘前待登乘人数＝上次剩余待登乘＋外部新增＋从其他节点到达。**

**本次剩余待登乘＝本次开始登乘前待登乘－本次开始登乘人数。**

候客安全检查同时加上仍在登乘的人数。运行中的旅客按线路运行时间延后到达，目的节点按群体吸收；最后到达目的节点的人数必须等于该过程的新增加初始人数。

线路有效能力受既定服务、选择的新增单位、核定人数及舒适容量共同限制。节点登乘能力、节点接收能力、选定线路的共用通道及新增单位登乘位分别约束，不能把同一资源在多个方式中重复计数。

### 目标

默认先减少各允许过程中的最坏累计全程人分钟，再在已取得的时间水平下择优新增预约费用。累计全程人分钟是每位旅客从进入到到达目的节点的分钟数加总，包含等待、登乘、运行和换乘；它与平均时间、个人最长等待及最后完成时刻是不同指标。

也可选择累计等待优先或预约费用优先。不同过程总人数可不同，默认目标采用累计人分钟取最大值，不等于各过程平均时间取最大值。平均指标另报，便于判断服务体验。

固定整数资源后，整理路径与站立负担，减少无必要的滞留与循环。平局整理中的过程求和不解释为发生概率。各阶段保存状态、界限与差距；限时未取得方案不能写为已证明无解。

### 舒适与费用

已测度方式使用座位、站立密度和站立持续时间：每段服务的站立人数乘该段运行分钟，累积为站立人分钟。可以设置全网络与各方式上限。步行等可标为当前未测度，其通行能力和时间仍检查，但不称为已经舒适。

费用是新增单位的预约费用；闲置预约仍计费。既定服务是共同条件，票价、合同费用和社会总成本不混用。

### 信息约束

所有允许过程共用新增预约。若截至某时刻看到的各群体进入历史相同，对应的服务分配必须相同；观察后能区分的过程才允许不同分配。信息提前量影响资源准备可用时刻。结果只对明确列出的过程集合保证，不自动覆盖所有未来变化。

## 五 与五维情景库的接口

| 五维字段 | 网络模型的输入表达 |
|---|---|
| 信息提前量 | 资源准备时长减提前量，形成最早可开始登乘时刻 |
| 到达不确定性 | 多条逐群体、逐时段进入过程，保留共同计划和历史一致约束 |
| 进入持续时间 | 进入段数乘时间步；之后不再增加外部旅客 |
| 新增待接续人数 | 各过程各群体进入人数之和；初始候客单列 |
| 方式与空间状态 | 方式启用、服务日历、线路、节点、资源窗口及共享设施 |

五维仍为组织字段，实际求解使用完整网络细节。没有把旧版保障等级指定为本模型必须输出的结果。

## 七 依据、取舍与适用范围

时间展开网络的建模思路参考公共交通时刻研究；[Pyrga等的作者机构记录](https://publikationen.bibliothek.kit.edu/1000015135)提供题名与正式发表信息。[2025年多方式枢纽联合疏运研究的出版者摘要](https://www.sciencedirect.com/science/article/pii/S0968090X25001214)说明其联合行人分配与车辆调度，并用时间展开网络处理子问题。本实现采用自主明确的网络流和资源约束，没有复现该文元胞传输、需求转换行为模型或变邻域算法；查阅范围以摘要为限。

舒适采用[国内公交拥挤成本研究](https://xuebao.neu.edu.cn/natural/CN/10.12068/j.issn.1005-3026.2021.11.020)所支持的拥挤状态与持续时间结构，测度迁移条件沿用[模型研究方案](../情景库驱动的接续运输优化模型研究方案-v1.md)。具体密度、站立负担和费用阈值均须有来源或明示假设，不移植为真实标准。

当前为固定运行时间、连续人流和离散时间步下的研究模型。网络容量、换乘、资源和完成可以检查；道路拥堵传播、轨道闭塞与列车追踪、驾驶员排班、旅客拒乘及现场指挥权限未内生求解。需要这些机制时，应补充相应结构及数据，不能只换一个方式名称就声称完成其全部专业调度。

平台第一版规模上限为12节点、36线路、12方式、16资源池、8群体、8过程与96时段。时间步可选5、10、15、20或30分钟；登乘和运行向上取整，返回及资源占用另按完整窗口核对。结果为给定网络下的条件研究结论，真实案例提供业务背景及辅助核对。
