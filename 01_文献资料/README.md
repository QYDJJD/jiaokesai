# 文献资料

本模块整理课题的理论、制度和方法依据，供情景库、建模与实验对照使用。

## 当前材料

- [研究综述（T-C3）](研究综述-T-C3.md)：7篇代表文献的分问题综述与迁移条件，区分全文和摘要核查；待梅玉坤复核。
- [研究背景（T-C1）](研究背景-T-C1.md)：政策依据、虹桥客流口径、事件问题与研究范围；张子凡主责，待梅玉坤复核。
- [多方式联动现状（T-C2）](多方式联动现状-T-C2.md)：组织基础、主体动作、信息执行过程及待核权限；张子凡主责，待万岩松复核。
- [灾害分级文献体系对照表](灾害分级文献体系对照表-优化版.md)：区分事件响应、枢纽对象分类和运营情景，记录原文核验范围。

## 后续研究内容

政策与应急预案、枢纽规模与关键词定义、情景构建方法、客流与运力建模、多方式调度、研究背景与综述。材料增多后按这些主题建立子目录。

每条文献记录作者或制定主体、年份与版本、题名、原文链接、页码或条款、适用对象、可借鉴内容和核验状态。已有分级对照不代表学术方法比较已完成。
