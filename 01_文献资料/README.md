# 文献资料

本模块整理课题的理论、制度和方法依据，供情景库、建模与实验对照使用。

## 当前材料

- [灾害分级文献体系对照表](灾害分级文献体系对照表-优化版.md)：区分事件响应、枢纽对象分类和运营情景，记录原文核验范围。
- [突发事件定义参考文献与方法依据](突发事件定义参考文献与方法依据.md)：汇总法律定义、预案口径和交通运输论文中“事件转译为运行状态”的方法依据。
- [超大型枢纽判定参考文献与方法依据](超大型枢纽判定参考文献与方法依据.md)：汇总标准、政策和论文中关于综合交通枢纽规模、网络、换乘、服务和运行状态的判定方法。
- [多方式协同联动参考文献与方法依据](多方式协同联动参考文献与方法依据.md)：汇总多方式应急疏散、车辆调度、方式选择和供给引导论文，支撑多方式划分与协同联动定义。

## 后续研究内容

政策与应急预案、枢纽规模与关键词定义、情景构建方法、客流与运力建模、多方式调度、研究背景与综述。材料增多后按这些主题建立子目录。

每条文献记录作者或制定主体、年份与版本、题名、原文链接、页码或条款、适用对象、可借鉴内容和核验状态。已有分级对照不代表学术方法比较已完成。

## 与其他模块衔接

向[情景库](../03_情景库/README.md)提供维度和分类依据，向[建模](../04_建模/README.md)提供变量与方法依据，向[实验验证](../06_实验验证/README.md)提供对照方法。事件原始记录、实际观测值和参数数据存入[数据与案例](../02_数据与案例/README.md)。
